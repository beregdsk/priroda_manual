               Описание исходных данных

  Исходные данные задаются в свободном формате без различия между заглавными
и строчными буквами. Различные задаваемые величины объединены в отдельные
разделы. Каждый раздел начинается с символа '$' за которым следует его
название и заканчивается словом '$end'. Внутри этих скобок задаются те или
иные величины одним из двух возможных способов:
    1. в произвольной последовательности в виде выражений присваивания
        переменная = значение
       для переменных целого, вещественного или строкового типа, или в виде
        переменная ( индекс ) = значение1 значение2 и т. д.
       для массивов целого или вещественного типов, причём индекс показывает,
       начиная с какого элемента массива задаются последующие значения.
       Название переменных могут быть заданы сокращённо лишь несколькими
       первыми буквами, достаточными для того, чтобы отличить одно название
       от другого, например, 'tol=0.0001' вместо 'tolerance=0.0001'.
    2. в определённой последовательности непосредственно без использования
       названий переменных и выражений присваивания.
Почти все задаваемые величины имеют определённые значения по умолчанию, так
что достаточно задавать лишь те из них, которые отличаются от этих значений.
  Приведём перечень разделов с объяснением их общего содержания:

 $control          основные управляющие величины
 $coordinates      координаты ядер
 $basis            параметры атомных базисов
 $auxiliary        параметры вспомогательных атомных базисов
 $guess            выбор начального приближения для волновых функций
 $SCF              величины, определяющие электронное состояние и способ
                   нахождения самосогласованного решения
 $search           величины, относящиеся к поиску стационарных точек на
                   поверхности потенциальной энергии
 $force            величины, управляющие численным вычислением матрицы
                   силовых постоянных
 $hessian          заданная матрица силовых постоянных

Приведём теперь для каждого раздела входящие в него переменные, их смысл,
возможные значения и величины, принимаемые по умолчанию. Будем использовать
скобки [] для обозначения непосредственно задаваемого значения.

 $control

  task =             тип расчёта
          check      распечатать некоторые исходные данные и больше ничего
                     не делать
          guess      получить начальное приближение для волновых функций
          energy     вычислить энергию для заданной геометрии (по умолчанию)
          optimize   поиск стационарной точки на поверхности потенциальной
                     энергии
          hessian    вычисление матрицы силовых постоянных

  basis =            файл, содержащий параметры атомных базисов
          input      текущий файл с исходными данными (по умолчанию)
          [название] указанный файл

 $end


 $coordinates

  В этом разделе сначала должно быть указано одно из двух ключевых слов:

   cartesian  - если задаются декартовы координаты ядер
   zmatrix    - если координаты ядер задаются z-матрицей

  В первом случае далее следуют атомные номера (целые числа) и координаты
  X, Y, Z в ангстремах последовательно для каждого атома:

   [атомный номер] [X] [Y] [Z]
   [атомный номер] [X] [Y] [Z]
   и т. д.

  Во втором случае последующие данные имеют вид

   [атомный номер]
   [атомный номер] [i1] [расстояние]
   [атомный номер] [i2] [расстояние] [j2] [угол]
   [атомный номер] [i3] [расстояние] [j3] [угол] [k3] [двухгранный угол]
   [атомный номер] [i4] [расстояние] [j4] [угол] [k4] [двухгранный угол]
   и т. д.

  где целые числа i, j, k - порядковые номера атомов, расстояния заданы в
  ангстремах, а углы - в градусах.

 $end


 $basis

  В этом разделе задаются параметры атомных базисов, используемых для
  разложения одноэлектронных волновых функций. Эти данные приводятся
  последовательно для того или иного атомного номера в виде

      [атомный номер] [число различных радиальных функций]
         [угловой момент] [число экспонент]
            [показатель экспоненты 1] [линейный коэффициент 1]
            [показатель экспоненты 2] [линейный коэффициент 2]
            и т. д.
         [угловой момент] [число экспонент]
            [показатель экспоненты 1] [линейный коэффициент 1]
            [показатель экспоненты 2] [линейный коэффициент 2]
            и т. д.
         и т. д.

 $end


 $auxiliary

  Этот раздел подобен предыдущему и содержит параметры вспомогательных
  атомных базисов для разложения электронной плотности, которые состоят
  из отдельных (несгруппированных) сферических гауссовых функций.
  Данные приводятся в виде

      [атомный номер] [число различных радиальных функций]
         [угловой момент][+]  [показатель экспоненты]
         [угловой момент][+]  [показатель экспоненты]
         и т. д.

  Если сразу после величины углового момента стоит знак '+', это значит,
  что используется набор всех функций с угловым моментом от 0 до заданной
  величины.

 $end


 $guess

  file = название двоичного файла из которого должны быть считаны
         коэффициенты разложения одноэлектронных волновых функций.
         По умолчанию, начальное приближение для этих коэффициентов
         берётся с помощью расширенного метода Хюккеля, что в
         большинстве случаев работает достаточно хорошо.

  n ()  = порядок, в котором следует расположить волновые функции начального
           приближения. По умолчанию n(1)=1 2 3 и т. д.
  na () = то же для случая спин-поляризованного расчёта
  nb () = . . .

  print = что напечатать
          0 - ничего (по умолчанию)
          1 - собственные значения, порядки связей
          2 - то же, а также собственные векторы

 $end


 $SCF

  charge       = полный заряд молекулы, по умолчанию 0
  multiplicity = спиновая мультиплетность, по умолчанию 1
  functional   = краткое название приближения для обменно-корреляционной
                 энергии по фамилиям авторов
                 BLYP:
                  [1] A.D. Becke, "Density-functional echange-energy
                      approximation with correct asymptotic behavior",
                      Phys. Rev. A 38 (1988), 3098.
                  [2] C. Lee, W. Yang, and R.G. Parr, "Development of
                      the Colle-Salvetti correlation-energy formula
                      into a functional of the electron density",
                      Phys. Rev. B 37 (1988), 785.
                 PBE:
                  [1] J.P. Perdew, K. Burke, M. Ernzerhof, "Generalized
                      Gradient Approximation Made Simple",
                      Phys. Rev. Lett. 1996.
                 по умолчанию используется функционал BLYP, но это вовсе
                 не значит что это лучший выбор.
  restricted   = провести ли спин-ограниченный расчёт
                 1 - да (по умолчанию)
                 0 - нет
                 Некоторые авторы утверждают, что для систем с открытыми
                 оболочками неверно использовать спин-ограниченный метод
                 расчёта, поскольку в этом случае одноэлектронные волновые
                 функции не являются решениями одночастичного уравнения
                 Шрёдингера с некоторым ЛОКАЛЬНЫМ потенциалом.
  field ()     = x, y, и z-составляющие внешнего однородного
                 электростатического поля в атомных единицах,
                 по умолчанию 0.0 0.0 0.0.
  fit          = использовать ли вспомогательный базис для приближённого
                 разложения электронной плотности
                 0 - нет (по умолчанию)
                 1 - да
  accuracy     = заданная точность численного интегрирования плотности
                 обменно-корреляционной энергии в атомных единицах (на атом),
                 по умолчанию 1e-6.
  convergence  = критерий сходимости самосогласования, наибольшая допустимая
                 величина недиагональных элементов гамильтониана (в атомных
                 единицах), по умолчанию 1e-5.
  iterations   = наибольшее число итераций самосогласования, по умолчанию 20.
  mix          = нарушить ли на первой итерации равенство волновых функций
                 для спина "вверх" и "вниз"
                 0 - нет (по умолчанию)
                 1 - да
  shift        = величина, которая прибавляется к диагональным элементам
                 гамильтониана, относящимся к незанятым уровням энергии,
                 перед его диагонализацией (в атомных единицах),
                 по умолчанию 0.5. Большие значения (1.5 ... 2.5) могут
                 понадобиться для обеспечения сходимости для систем с
                 низколежащими возбуждёнными состояниями.
  save         = название двоичного файла, в который следует сохранить
                 коэффициенты разложения одноэлектронных волновых функций
                 в самом конце расчёта. По умолчанию они не сохраняются.
  print        = количество печати
                 0 - как можно меньше (по умолчанию)
                 1 - умеренно
                 2 - много

 $end


 $search

  saddle       = вести ли поиск переходного состояния
                 0 - нет (по умолчанию)
                 1 - да
  tolerance    = критерий сходимости оптимизации - наибольшая
                 допустимая величина элементов вектора градиента
                 (в атомных единицах), по умолчанию 0.001.
  steps        = наибольшее число шагов оптимизации, по умолчанию 15.
  trust        = наибольшая допустимая величина приращения координат на
                 очередном шаге оптимизации (в атомных единицах) -
                 доверительный радиус, по умолчанию 0.2.
  internals () = целочисленный массив, задающий внутренние координаты для
                 проведения оптимизации геометрии. Последовательно вводятся
                 следующие возможные сочетания чисел:
                  1 i j     - расстояние между атомами i и j.
                  2 i j k   - угол, заданный тройкой атомов i, j и k.
                  3 i j k l - двухгранный угол, заданный четвёркой
                              атомов i, j, k и l.
                 По умолчанию, если исходная геометрия в разделе
                 $coordinates задана в виде z-матрицы, используются
                 соответствующие внутренние координаты. Для отмены
                 использования внутренних координат следует задать
                 internals=0.
  follow       = порядковый номер собственного вектора гессиана, в
                 направлении которого следует искать максимум при поиске
                 переходного состояния, по умолчанию 1.
  vector       = явным образом заданное направление поиска максимума.
  curvature    = соответствующая заданная кривизна поверхности потенциальной
                 энергии вдоль этого направления.
  fix ()       = порядковые номера внутренних координат, которые должны
                 оставаться постоянными при оптимизации геометрии.
  scan         = порядковый номер внутренней координаты, по которой ведётся
                 "сканирование".
  value ()     = значения (в ангстремах или градусах), которые должна
                 принимать указанная внутренняя координата при
                 "сканировании".
  iscan,
  jscan        = порядковые номера двух внутренних координат, из которых
                 первая меняется наиболее быстро. Используются для
                 построения двухмерной поверхности потенциальной энергии.
  ivalue (),
  jvalue ()    = наборы значений, которые должны принимать выбранные
                внутренние координаты.

 $end


 $force

  points = по скольким точкам проводить численное дифференцирование
           1 - по одному смещению для каждой координаты (по умолчанию).
           2 - по двум смещениям в положительном и отрицательном
               направлениях (в два раза дольше, но несколько точней).
  delta  = величина смещения в атомных единицах, по умолчанию 0.0025.
           Следует учесть, что чем меньше величина delta, тем большие
           требования к точности сходимости ССП, в частности, для
           указанной величины 0.0025 желательно потребовать conv=1e-6
           в разделе $SCF.

 $end


 $hessian

  В этом разделе непосредственно задаются элементы матрицы силовых
  постоянных в атомных единицах, в виде верхнего треугольника. Обычно эти
  данные печатаются самой программой. Эта матрица считывается при поиске
  стационарных точек на поверхности потенциальной энергии.

 $end
