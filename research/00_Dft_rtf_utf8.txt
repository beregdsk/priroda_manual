В файле с исходными данными программой воспринимаются лишь выражения, записанные внутри соответствующих разделов, открываемых ключевыми словами, начинающимися со знака $ и закрывающимися ключевым словом $end .
Пробелы и переводы строки могут добавляться между числами, словами и знаками = ( ) , по желанию.
В каждом разделе нужные величины задаются либо в виде выражений присваивания, либо в виде определённой последовательности чисел.
В общем виде присваивания имеют вид название_переменной (i) = значение_i , значение_i+1 , ...
например:
a(5)=1.0, 2.0, 3.0
что изменяет установленные по умолчанию значения величин a(5), a(6) и a(7) на 1.0, 2.0 и 3.0 соответственно.
Отсутствие индекса со скобками равносильно присваиванию начиная с первого элемента, то есть a=3,4,5 равносильно a(1)=3,4,5 .
Большинство величин требуют только одного значения, что записывается проще всего, например: a=3 .
В любом случае название переменной можно сократить, но настолько, чтобы её можно было отличить от других, например, вместо accuracy=1e-8 проще написать accur=1e-8 .

Основные разделы данных с указанием значений по умолчанию.

$system
 memory=16	 Ограничение на используемую память, в мегабайтах.
 disk=1 	Ограничение на используемое дисковое пространство, в гигабайтах. На каждый новый гигабайт будет открыт отдельный файл, избегая таким образом налагаемые некоторыми операционными системами ограничения на размер одного файла.
 disk=-400	Использование оперативной памяти в качестве дискового пространства в Mb.
$end

$control
 theory= 	 Метод расчета:
dft по умолчанию 
RIMP2 – ускоренный метод MP2 (RI-MP2).
 task=” “	 Тип расчёта. Возможный выбор:
	check	Рассчитывать только геометрию
energy	 Рассчитать энергию для заданной геометрии
gradient 	То же, но ещё и первые производные энергии по координатам ядер, что требует несущественно большего времени, но даёт больше сведений, поэтому принято по умолчанию
optimize 	Оптимизация геометрии, в том числе поиск переходного состояния
hessian  	Расчёт вторых производных энергии по координатам ядер с последующим колебательным анализом. Возможно совмещение: optimize+hessian.
irc		Расчет координаты реакции в атомных единицах – bohr*m1/2
scan		Режим сканирования по одному или нескольким параметрам.
basis=""	Название файла, из которого следует взять атомные базисы и, если нужно, псевдопотенциалы:
По умолчанию -- пустое значение, что подразумевает, что эти данные приводятся в самом файле, что обычно малоудобно.
3z.bas – полноэлектронный базис (до 54 элемента)
sbk.bas – базис с псевдопотенциалом (только валентные электроны), учитывающим релятивистские поправки (до 84 элемента)
ccpvnz.bas – базис для метода MP2. Соответствующие вспомогательные базисы доступны для set=2z, set=3z, set=4z, т.е. cc-pVDZ, cc-pVTZ, cc-pVQZ.
 save=file.vec	Имя файла, в который будут записаны вектора.
 print=+molden	Вывод колебаний в формате Molden при task=hessian. По окончании расчета из файла file.out извлекаем: grep “freq>” file.out > file.freq и затем из файла file.freq удаляем из всех строк символы “freq>”. Запускаем molden file.freq.
 print=+vectors+molden	Вывод собственных векторов в формате Molden. По окончании расчета из файла file.out извлекаем: grep “mos>” file.out > file.mos и затем из файла file.mos удаляем из всех строк символы “mos>”. Запускаем molden file.mos.
$end

$guess
 read=0 	Нет считывания векторов из файла file.vec
 read=1 	Считывание векторов из файла file.vec
 n(Ni)=NI+k,NI,NI+1, … NI+k-1 	изменение в последовательности векторов (для случая, когда вакантные вектора по энергии оказываются ниже занятых)
 nb(Ni)=NI+k,NI,NI+1, … NI+k-1	то же для beta-векторов (открытые оболочки)
$end

$molecule
 charge=0        заряд молекулы.
 multip=1        спиновая мультиплетность.
далее должно следовать одно из двух ключевых слов, z-matrix или cartesian .
z-matrix
 В этом случае далее следуют числа в виде хорошо известной z-матрицы с атомными номерами (а не символами элементов) . Очередной i-ый атом задаётся либо в виде
  q  j  r(i-j)  k  a(i-j-k)  l  b(i-j-k-l)
 где
 q -- атомный номер,
 r -- расстояние i-j,
 a -- угол i-j-k,
 b -- двухгранный угол i-j-k-l;
 либо в виде
  q  j  r(i-j)  k  a(i-j-k) -l  a(i-j-l)
 где вместо двухгранного угла i-j-k-l использован второй угол i-j-l;
 либо в виде
  q  j  r(i-j) -k   r(i-k)   l  b(i-j-k-l)
 где вместо угла i-j-k использовано второе расстояние i-k;
 либо, наконец, в виде
  q  j  r(i-j) -k   r(i-k)  -l  r(i-l)
 используя три расстояния.
cartesian
 В этом случае каждый атом задаётся атомным номером и тремя декартовыми координатами:
  q  x  y  z
 Кроме того, за набором атомов, заданных декартовыми координатами, можно ввести ещё нужное количество атомов с помощью z-матрицы, введя после декартовых координат ключевое слово z-matrix и соответствующую последовательность чисел, начиная, естественно, уже для первого из них с трёх чисел и привязывая его к уже заданным атомам.
$end

$optimize
 saddle=0 	Проводить ли поиск переходного состояния. По умолчанию будет проводиться минимизация энергии. В случае поиска переходного состояния (saddle=1) необходимо присутствие во входных данных матрицы вторых производных.
 follow=1	По умолчанию (номер колебательного вектора при оптимизации переходного состояния)
 tolerance=1e-4 	Допустимое значение градиента, при котором можно заканчивать оптимизацию.
 trust=0.5 	Допустимая величина приращения геометрических параметров на каждом шаге оптимизации, вводимая для избежания слишком сильных рывков.
 steps=50 	Наибольшее число шагов оптимизации. Не стоит увлекаться большим числом шагов -- если нет сходимости за, скажем, 50 шагов, весьма вероятно, что что-то не так. Очень помогает во многих случаях перед оптимизацией рассчитать матрицу вторых производных и подать её в исходных данных, тем более что она весьма быстро считается.
 fix=0,0,0,0,0 	Возможность задать ряд геометрических параметров, которые не должны меняться в ходе оптимизации. Последовательность пятёрок чисел, имеющих вид 1,i,j,0,0 -- расстояние i-j;    2,i,j,k,0 -- угол i-j-k;    3,i,j,k,l -- двухгранный угол i-j-k-l.
 value=0.0,0.0,	Задаются все начальные, а затем все конечные значения для всех выше указанных параметров, в ангстремах и градусах при режиме task=scan.
 points=	Задается число точек для режимов task=irc и task=scan.
 radius=0.2	Длина шага в режиме task=irc
 back=0 (1)	Направление спуска из седловой точки в режиме task=irc
$end

$scf
functional=PBE 	Используемый функционал плотности. Другой выбор -- BLYP, который менее точен и менее теоретически состоятелен.
convergence=1e-6 	Точность решения уравнений ССП. Лишь в редких случаях может понадобиться более высокая точность.
iterations=30	 Допустимое число итераций. Разрешать слишком много итераций нецелесообразно - напрасная трата времени, лучше попытаться понять причину плохой сходимости.
procedure=NR 	Алгоритм решения уравнений ССП. NR -- квадратически сходящийся метод, который к тому же может справляться даже с неправильной исходной электронной конфигурацией, но в некоторых тяжёлых случаях может лопнуть. Тогда последний выход - попробовать proc=BFGS, который так страшно не лопается, но обычно медленнее и иногда плохо сходится.
$end

$grid
accuracy=1e-7	Точность численного интегрирования. Чем больше точность, тем больше вычислительные затраты. Значение 1e-6 может быть полезно для грубой оптимизации геометрии (tol=1e-3, см. выше). Значение 1e-8 понадобится для особо точной оптимизации геометрии (если, например, молекула весьма гибкая) до уровня tol=1e-5. Точнее чем 1e-8 заказывать не имеет глубокого смысла - заложенные в программе формулы численного интегрирования всё равно не позволяют достигать неограниченной точности.
$end

$hessian
 Здесь задаётся матрица вторых производных для использования в оптимизациях геометрии или для колебательного анализа с другими изотопами и термохимии. В ручную набивать не стоит -- проще взять из расчёта при task=hessian. Обязательно в режимах task=optimize, task=optimize+hessian при sad=1, а также task=irc.
$end
